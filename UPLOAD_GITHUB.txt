UPLOAD TO GITHUB (required for image build)
==========================================
1. Open https://github.com/cannoi/pinode-telegram-solohost
2. Extract THIS zip at the REPO ROOT (same folder as README).
   Do NOT keep a nested folder like github-SoloHost-v2.6.60/
3. Required at repo root:
   Dockerfile
   loader.js
   app.js
   package.json
   telemetry-lite.js
   .github/workflows/docker-publish.yml
4. Commit to main.
5. Actions -> "Build and publish SoloHost image"
6. Image:
   ghcr.io/cannoi/pinode-telegram-solohost:v2.6.60

Build image: bash scripts/build-image.sh
Push: PUSH=1 bash scripts/build-image.sh
